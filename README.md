## What is this?
Welcome to the Obsidian notetaking skeleton vault. This includes the configurations and settings used to keep track of your ideas, meetings, notes, and projects. Obsidian is a **markdown-based personal knowledge management tool** that helps you build a network of linked notes.

## How do I set it up?
1. Make sure you down load Obsidian to your machine! It is a very powerful note taking app that relies on simple markdown files!
2. Download the repository as a zip file.
3. Right click on the zip file and click "Extract All". This will open up a dialogue for you to select where you what your notes to live. By clicking browse you can select a specific place in your folder structure. Unless you want to pay for [Obsidian Sync](https://obsidian.md/sync) (4$/month), I recommend putting this in your one drive so it can sync across any work laptops (and even your phone if you add one drive to it!).
4. Once you have extracted the files, open Obsidian and select "Open a folder as a vault".  
5. You're done! Feel free to explore the rest of this page or [Obsidan's Website](https://obsidian.md/) for extra documentation and information.

## 🚀 First Steps After Installation

### 1. **Create or Open a Vault**

- A **vault** is a folder on your computer that contains your notes.
- Go to **"Open folder as vault"** or **"Create new vault"** to get started.
- All notes in a vault are stored as `.md` (Markdown) files.

### 2. **Basic Note Creation**

- Click the “+” icon or use the shortcut `Ctrl+N` (`Cmd+N` on Mac) to create a new note.
- Name your note and start typing. Obsidian autosaves as you write.

### 3. **Markdown Basics**

Obsidian uses Markdown for formatting. Here are a few essentials:

| Action         | Syntax Example       |
| -------------- | -------------------- |
| Heading 1      | `# Title`            |
| Bullet list    | `- Item` or `* Item` |
| Bold           | `**bold**`           |
| Italic         | `*italic*`           |
| Link to a note | `[[Note Title]]`     |
| Code block     | ```your code```      |
| Task list      | `- [ ] Task item`    |

## 🔗 Linking and Structure

### Internal Links (`[[ ]]`)

- Use `[[Note Name]]` to create a **link to another note**.
- If the note doesn't exist yet, Obsidian will offer to create it.
### Tags (`#tag`)

- Use `#tags` in notes to group or categorize them.
- Tags can be searched and filtered globally.

### Backlinks

- Open a note and view **Backlinks** in the right sidebar to see what other notes link to it.
- This builds a **web of connected knowledge**.

---

## 🗂️ Organizing Notes

### Folders

- Create folders to organize your notes manually (e.g., `Meetings`, `Projects`, `Resources`).
### Templates

- Use the **Templates plugin** to insert pre-defined text (e.g., meeting notes, daily journal).
- Enable under **Settings > Core Plugins > Templates**.

---

## 🔍 Searching and Navigating

- Use `Ctrl+O` / `Cmd+O` to **quick open** a note.
- Use `Ctrl+Shift+F` to **search** across all notes.
- Use the **Graph View** to visualize links between notes.

---
## 🛠️ Best Practices

- Use short, descriptive note titles (e.g., `Project Kickoff – Client X`).

- Link generously between notes using `[[ ]]` to form natural relationships.

- Don’t over-organize—Obsidian works best when notes are connected, not buried in folders.

- Regularly use **Daily Notes** to track ongoing thoughts, ideas, or to-do lists.
